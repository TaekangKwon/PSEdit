# 한국어 문체 패턴 사전

구조 점검(structure-checklist.md)을 통과한 뒤에 쓴다. 문체 수정이 결론 명확화보다 앞서면 안 된다.

## 사용법

- **수정 순서**: 입장 → 주체 → 구조 → 어휘 → 기호. 앞 단계를 고치면 뒤 단계 문제가 같이 사라지는 경우가 많다.
  - 입장: 글쓴이가 결론을 말하고 있는가, 피하고 있는가
  - 주체: 누가 하는지 보이는가 (사물 주어·피동 남용)
  - 구조: 문장·문단 짜임 (나열 강박, 반복 틀)
  - 어휘: 번역투·과장어·고빈도 어휘
  - 기호: 대시·굵은 글씨·따옴표·이모지
- **심각도**
  - 결정적: 한 번만 나와도 고친다.
  - 강: 같은 패턴(표의 한 행)이 한 문서에 3회 이상이거나, 한 문단에 서로 다른 패턴이 3개 이상 몰려 있으면 고친다.
  - 약: 다른 패턴과 같은 문단에 겹쳐 있을 때만 고친다.
  - 고치는 순서는 결정적 → 강 → 약.
- 패턴 하나만으로 "AI 문체"라고 판단하지 않는다. 여러 신호가 몰린 곳을 고친다.
- 패턴에 걸려도 뜻이 정확하고 대체 표현이 더 길어지면 두어도 된다. 기계적으로 바꾸지 않는다.
- 고칠 때도 부정·조건·시제·확실도·단위는 바꾸지 않는다.
  - 확실도 표현(추측·가능성)은 한 주장에 겹친 것만 줄이고 **마지막 하나는 남긴다.** 단정으로 바꾸는 것은 작성 모드에서 근거가 있을 때뿐이고, 윤문에서는 하지 않는다.
  - 가능·능력의 "~할 수 있다"는 추측 표현이 아니다. "재사용할 수 있을 것으로 보인다"는 추측이 하나뿐이므로 고치지 않는다.
  - 문장 일부를 지울 때는 대비·한정을 나타내는 말("~ 대신", "~가 아니라", "~만")을 남긴다. 지우면 뜻이 바뀐다.

## 1. 입장 — 결론 회피 (결정적)

| 패턴 | 예 | 고치는 법 |
|---|---|---|
| 추상어로 끝내기 | "보안이 중요합니다", "검토가 필요합니다", "고민이 필요한 시점입니다" | 무엇을 할지로 바꾼다: "토큰 만료를 1시간으로 줄인다" |
| 양쪽 다 맞다 | "장단점이 있으므로 상황에 따라 선택하면 됩니다" | 추천 하나 + 조건: "A를 쓴다. 단, X이면 B" |
| 결론 없는 결론 | "다양한 측면에서 종합적으로 판단해야 합니다" | 판단 기준과 판단 결과를 쓴다 |
| 헤지 겹치기 | "~일 수도 있을 것으로 보입니다" | 추측을 하나만 남긴다: "~일 수 있다". 단정은 작성 모드에서 근거가 있을 때만 |

## 2. 입장 — 앞말·메타 발화 (강)

| 패턴 | 고치는 법 |
|---|---|
| "솔직히 말씀드리면", "사실", "참고로 말씀드리면" | 지운다 |
| "중요한 점은 ~라는 것입니다" | 내용만 쓴다 |
| "~에 대해 알아보겠습니다", "~를 살펴보면 다음과 같습니다" | 지우고 바로 내용 |
| "좋은 질문입니다", "말씀하신 대로" | 지운다 |
| "결론부터 말씀드리면" 뒤에 결론이 아닌 내용 | 표현을 지우고 진짜 결론을 쓴다 |
| 틀에 박힌 첫머리: "오늘은~", "빠르게 변화하는 오늘날~" | 지우고 바로 내용 |
| 틀에 박힌 맺음: "도움이 되셨길 바랍니다", "궁금한 점이 있으시면 언제든지", "함께 ~해봅시다!" | 지운다 |
| 결론 뒤에 덧붙인 문장 ("결론적으로", "요컨대"로 시작해 앞말을 되풀이) | 지운다 |

## 3. 주체 — 사물 주어·피동 (강)

| 패턴 | 예 | 고치는 법 |
|---|---|---|
| 이중 피동 | "되어지다", "보여지다", "만들어지게 되다" | "되다", "보이다", "만들다" |
| 행위자 없는 피동 | "설정이 변경되어야 합니다" | "운영팀이 설정을 바꾼다" (행위자를 알 때만) |
| 사물 주어 + 타동사 | "이 결과는 우리에게 ~을 말해 준다" | "이 결과로 ~을 알 수 있다" |
| "~에 의해 ~되다" | "관리자에 의해 승인된다" | "관리자가 승인한다" |

## 4. 구조 (강~약)

| 패턴 | 심각도 | 고치는 법 |
|---|---|---|
| 셋 나열 강박 ("A, B, 그리고 C" 반복) | 약 | 실제 개수대로. 둘이면 둘 |
| "A가 아니라 B다" 틀 반복 | 강 | 한 번이면 둔다. 반복되면 B만 쓴다 |
| 문단마다 끝에 요약 문장 | 강 | 지운다 |
| 질문형 소제목 ("왜 중요할까요?") | 약 | 내용을 담은 소제목: "토큰을 줄여야 하는 이유" |
| "**키워드**: 설명" 목록 남발 | 약 | 표 또는 문장 |
| 명사 나열 ("효율성 제고를 위한 방안 마련 추진") | 강 | 동사로 풀기: "효율을 높일 방안을 만든다" |
| 「~인 것이다」 3회 이상 | 결정적 | "~이다" |
| 문장 끝이 같은 꼴로 계속됨 ("~합니다." 다섯 번 연속 등) | 약 | 문장을 합치거나 끝맺음을 바꾼다 |
| 문장 첫머리 접속어 과다 (또한, 뿐만 아니라, 더불어, 나아가, 아울러, 따라서, 즉) | 강 | 지워도 뜻이 통하면 지운다 |
| 기계적 「첫째/둘째/셋째」, 짧은 내용의 과도한 글머리표 | 약 | 번호 목록 또는 한 문장 |
| 형식 명사 과다 (것, 점, 수, 바) | 약 | "~할 수 있는 점이 있다" → "~할 수 있다" |

## 5. 어휘 — 번역투 (강)

| 패턴 | 고치는 법 |
|---|---|
| ~에 있어서 (3회 이상이면 결정적) | ~에서, ~할 때 |
| ~하는 것이 가능하다 | ~할 수 있다 |
| ~을 가지고 있다 (have) | ~이 있다 |
| ~에 대한 ~에 대한 (겹침) | 한 번으로 줄이거나 동사로 |
| ~을 통해 (과다) | ~로, ~해서 |
| ~로 인해 | ~ 때문에, ~로 |
| ~하는 중에 있다 | ~하고 있다 |
| 그것은 / 이것은 (대명사 주어 반복) | 가리키는 말을 직접 쓰거나 생략 |
| ~함에 있어 | ~할 때 |
| ~라고 할 수 있다 | 단정하거나 근거를 붙인다 |

## 6. 어휘 — 지시어 과다 (약, 몰리면 강)

「이러한」「해당」「이는」「이를 통해」「이에 따라」. 1,000자에 5회를 넘으면 가리키는 대상을 직접 쓴다. (기준값은 hook fixture로 조정)

## 7. 어휘 — 과장·AI 고빈도 어휘 (약, 몰리면 강)

| 어휘 | 고치는 법 |
|---|---|
| 활용하다 | 쓰다 |
| 극대화, 최적화 | 무엇을 얼마나: "응답 시간 30% 단축" |
| 시사하다, 시사점 | "~을 알 수 있다", "우리에게 의미하는 것" |
| 혁신적, 획기적, 강력한, 완벽한 | 지우거나 수치로 |
| 다양한, 효과적인, 원활한, 체계적인 | 구체적으로 무엇인지 |
| 핵심적, 필수적, 중요한 | 왜 그런지 한 줄 또는 삭제 |
| 인사이트, 시너지, 패러다임, 생태계, 여정, 게임 체인저 | 쉬운 말로 |
| 한층, 더욱, 매우, 상당히 (반복) | 지우거나 수치로 |
| 제고, 도모, 강구, 모색, 도출 | 높이다, 꾀하다, 찾다, 내다 |
| 함의, 방증하다, 저변, ~의 일환으로 | 쉬운 말로 풀거나 지운다 |
| 새로운 지평을 열다, 단순한 ~를 넘어 | 무엇이 달라지는지 구체적으로 |
| 영어 병기 과다 ("효율성(Efficiency)") | 독자가 아는 말이면 지운다. 단, 용어 규칙이 첫 등장 병기를 요구하면 그 규칙을 따른다 |

## 8. 기호 (약)

| 패턴 | 고치는 법 |
|---|---|
| 대시(—) 남발 | 쉼표·마침표·괄호 |
| 굵은 글씨 한 문단에 3곳 이상 | 몰린 그 문단에서 1곳만 남긴다 |
| 강조용 따옴표 남발 | 지운다 |
| 느낌표, 이모지 머리표 | 지운다 |

## 9. 쉬운 공공언어 관점 (약)

- 어려운 한자어 → 쉬운 말: 상기(위), 익일(다음 날), 금번(이번), 기 수행한(이미 한), 득하다(얻다).
- 외래어 → 우리말이 자리 잡은 것은 우리말: 이슈(문제·쟁점), 리스크(위험), 프로세스(절차). 단, 팀이 이미 쓰는 기술 용어는 그대로 둔다.
- 한 문장 100자 안팎을 넘으면 나눈다.
