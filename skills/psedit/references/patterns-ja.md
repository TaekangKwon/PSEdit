# 日本語 文体パターン辞書

構成チェック（structure-checklist.md）を通ってから使う。文体の修正を結論の明確化より先にしない。

## 使い方

- **直す順番**：立場 → 主体 → 構造 → 語彙 → 記号。前の段階を直すと後ろの問題が一緒に消えることが多い。
  - 立場：書き手が結論を言っているか、避けているか
  - 主体：誰がするのかが見えるか（無生物主語・受け身の多用）
  - 構造：文・段落の組み立て（3つ並べ、決まった型の繰り返し）
  - 語彙：翻訳調・誇張語・口癖語
  - 記号：ダッシュ・太字・かぎ括弧・絵文字
- **重大度**
  - 決定的：1回でも直す。
  - 強：同じパターン（表の1行）が1文書に3回以上、または1段落に異なるパターンが3つ以上集まっていれば直す。
  - 弱：同じ段落でほかのパターンと重なるときだけ直す。
  - 直す順番は 決定的 → 強 → 弱。
- パターン1つだけで「AI文体」と判断しない。複数のシグナルが集まっている所を直す。
- 書き手の声（敬体・常体、くだけた言い回し）は残す。敬体の文書を常体に変えない。
- 直すときも否定・条件・時制・確度・単位は変えない。
  - 確度の表現（推量・可能性）は、1つの主張に重なった分だけ減らし、**最後の1つは残す。** 言い切りに変えるのは作成時に根拠があるときだけで、ブラッシュアップではしない。
  - 可能・能力の「〜できる」は推量ではない。「再利用できると考えられる」は推量が1つだけなので直さない。
  - 段落や文の一部を削るときは、対比・限定の語（「〜の代わりに」「〜ではなく」「〜だけ」）を残す。消すと意味が変わる。

## 1. 立場 — 結論の回避（決定的）

| パターン | 例 | 直し方 |
|---|---|---|
| 抽象語で締める | 「〜が重要です」「〜が求められます」「〜が鍵となります」 | 何をするかに変える：「トークンの有効期限を1時間にする」 |
| どちらとも言える | 「ケースバイケース」「一概には言えませんが」「賛否が分かれる」 | 推奨1つ＋条件：「Aにする。ただしXならB」 |
| 推量で逃げる | 「〜と言えるでしょう」「〜ではないでしょうか」「〜と言えなくもない」 | 作成時：根拠を添えて言い切る。ブラッシュアップ時：確度は変えず、回りくどさだけ直す（「〜と考えられる」） |
| ぼかしの重ね | 「〜の可能性があるかもしれません」 | 推量を1つだけ残す（0にしない）：「〜の可能性がある」 |
| 読み手の行動が曖昧 | 「ご確認ください」だけで終わる | 何を確認して、どうすればよいかを書く |

## 2. 立場 — 前置き・メタ発話（強）

| パターン | 直し方 |
|---|---|
| 「〜について解説します」「以下で説明します」「それぞれ順に見ていきましょう」 | 消してすぐ本題 |
| 「ここで重要なのは」「ポイントは以下の通りです」 | 中身だけ書く |
| 「結論から言うと」の後に結論でない内容 | 表現を消して本当の結論を書く |
| 「近年〜が注目されています」「現代社会において」 | 消す |
| 「いかがでしたでしょうか」「ぜひ参考にしてください」 | 消す |
| 見出しをそのまま言い直す最初の1文 | 消す |

## 3. 主体 — 無生物主語・受け身（強）

| パターン | 例 | 直し方 |
|---|---|---|
| 行為者のない受け身 | 「設定が変更される必要があります」 | 「運用チームが設定を変える」（行為者が分かるときだけ） |
| 無生物主語＋他動詞 | 「この結果は〜を示唆している」 | 「この結果から〜が分かる」 |
| 「〜によって〜される」 | 「管理者によって承認される」 | 「管理者が承認する」 |
| 本文中の「本稿」「筆者」 | | 消すか「この文書」 |

## 4. 構造（強〜弱）

| パターン | 重大度 | 直し方 |
|---|---|---|
| 「AではなくBだ」の繰り返し | 強 | 1回なら残す。繰り返すならBだけ書く |
| 「Aでも、Bでもなく、Cだ」 | 強 | Cだけ書く |
| 「3つの観点から」「3つの原則」（数合わせ） | 弱 | 実際の数で。2つなら2つ |
| 体言止めの断片を重ねる演出（「速く。正確に。」） | 強 | 普通の文に |
| 「誰もが〜だ。しかし——」 | 強 | 主張だけ書く |
| 段落ごとに「〜と感じました」等の同じ締め | 弱 | 文末を変えるか文を統合 |
| 疑問形の見出し（「なぜ〜なのか？」） | 弱 | 中身を表す見出し |
| 誇張したタイトル（「完全ガイド」「徹底解説」「〜が教えてくれること」） | 強 | 内容を表すタイトル |
| ❌/✅ の対比リスト | 弱 | 表 |
| 「説明します:」の直後にリストやコードブロック | 弱 | 1文で何のリストかを書く |
| 太字・ダッシュ・絵文字で始まるリスト項目 | 弱 | 普通の項目か表 |
| 文頭の接続語の多用（さらに、加えて、また） | 強 | 消しても通じるなら消す |

## 5. 語彙 — 翻訳調・冗長表現（強）

| パターン | 直し方 |
|---|---|
| 〜することが可能です、〜することができます | 〜できます、〜します |
| 〜において（多用） | 〜で |
| 〜に関して、〜に対して（重ね） | 1回に減らすか動詞で |
| 〜を持つ（have） | 〜がある |
| 〜を行う（する化） | 〜する：「確認を行う」→「確認する」 |
| 〜の役割を果たしています | 〜です |
| 〜が期待されます | 誰が何を期待するかを書くか、事実だけ書く |
| 〜に他なりません | 〜です |
| 示唆している、浮かび上がる、浮き彫りにする、位置づける | 分かる、見える、明らかにする |
| まず最初に | まず |
| 〜となっております、〜させていただきます（過剰） | 〜です、〜します |

## 6. 語彙 — 指示語の多用（弱、集まれば強）

「このような」「これにより」「当該」「その上で」。1,000字に5回を超えたら、指している対象を直接書く。（基準値はhook fixtureで調整）

## 7. 語彙 — 誇張語・口癖語（弱、集まれば強）

| 語 | 直し方 |
|---|---|
| 革新的、画期的、革命的、圧倒的、劇的に、飛躍的に、魔法のように、最高の | 消すか数値で |
| 完全に、非常に、本当に（1段落に2回以上）、〜すぎる（繰り返し） | 消すか数値で |
| シームレス、包括的、多角的、最適な、強力な | 具体的に何か |
| 本質的、解像度、腹落ち、手触り、熱量、営み | 普通の言葉で |
| 真理、境地、美学、結晶（大げさな名詞） | 消す |
| 羅針盤、地図、土台、車の両輪、DNA、触媒（決まった比喩。1文書2回まで） | 直接言う |
| 思考のOSをアップデート、〜をハック（カタカナ比喩） | 直接言う |
| コミット、アライン、ディープダイブ（ビジネス用語） | 約束する、そろえる、詳しく調べる。ただしチームで定着した用語は残す |
| 曖昧な形容詞（高速な、大量の） | 数値：「200ms以内」「1万件」 |

## 8. 記号（弱）

| パターン | 直し方 |
|---|---|
| ダッシュ（——、──）の多用 | 読点・句点・かっこ |
| 太字（`**`）が1段落に3か所以上 | 集まったその段落で1か所だけ残す |
| 強調のためのかぎ括弧 | 消す |
| 感嘆符、均等にばらまいた絵文字 | 消す |
| 全角文中の不要な半角スペース | 消す |

## 9. 公用文作成の考え方からの観点（弱）

- 結論は最初の段落に書く。
- 読み手の専門性に合わせる：専門用語は初出で1行説明（`stakeholder`・`end-user` 向け）。
- 1文は80字前後を超えたら分ける。
- 漢語・外来語は、読み手が知っている言い方に。チームの技術用語はそのまま。
