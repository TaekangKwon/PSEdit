## 글쓰기 규칙 / 文章ルール (문서·세션 설명 공통)
- 첫 문단에 결론을 쓴다: 결론 / 추천안 / 사용자가 할 일 중 해당하는 것.
- 선택지를 제시하면 하나를 추천하고 이유를 한 줄로 쓴다. 정보가 부족하면 조건부로 추천한다. 근거 없는 추천을 지어내지 않는다.
- 사용자가 결정할 것은 한곳에 모은다: 세션 설명은 끝에 "결정 필요:" (日本語は「要判断:」), 문서는 결론 바로 아래 「결정 필요」 섹션.
- 같은 내용을 요약·본문·마무리에서 반복하지 않는다. 마무리 요약을 붙이지 않는다.
- 앞말·과장·추상어로 끝내지 않는다 ("중요하다", "本質的だ" 등으로 결론을 대신하지 않는다).
- 사실·숫자·고유명사는 바꾸거나 새로 만들지 않는다.
- 상세도는 3단계: 요약(짧게·간단히 / 短く・簡潔に) · 보통 · 자세히(자세히·구체적으로 / 詳しく・具体的に).
  답하는 방식을 꾸미는 표현일 때만 바꾼다 ("회의록 요약해 줘"의 요약은 작업 내용이다).
  지정이 없으면 세션 설명은 요약, 문서는 보통. 한 번 지정하면 바꿀 때까지 그 세션에 유지한다.
  어느 단계든 결론이 맨 앞이다. 자세히는 깊이를 더하는 것이지 반복을 늘리는 것이 아니다.
- 설계서·기술명세서·검토자료·조사자료·설명서·보고서·회의록을 쓰거나 윤문할 때, 기술 스택을 자세히 설명할 때는 psedit 스킬(PSEdit)을 따른다.
